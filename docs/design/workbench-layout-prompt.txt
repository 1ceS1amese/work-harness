Use case: ui-mockup. Create a high-fidelity desktop interface design board for an existing Chinese multi-agent workbench named "Work Harness", inspired by Codex desktop's quiet neutral dark workspace. This is a proposed product UI, not an official OpenAI screenshot. Landscape 3:2 design board containing two large carefully aligned app windows: primary HOME window across upper two thirds and a smaller SETTINGS window and MOBILE inset across lower third. No device hardware, decorative wallpaper, gradients or marketing text.
Design language: monochrome charcoal main canvas #181818, sidebar #131313, elevated inputs #222222, fine #303030 borders, warm white text, muted gray labels, restrained sage green connection dot only. System sans-serif Chinese typography, elegant compact icons, 8px grid, generous whitespace. Shared shell in BOTH windows: 52px vertical utility icon rail on far left with work/home, history, settings and theme icons; 224px contextual sidebar; identical 52px horizontal title bar in main pane with breadcrumb and small connection state. Main content aligns to an 800px central column.
HOME: Brand Work Harness at top of contextual sidebar, new task action, search, 会话 section, simple short thread titles, local storage note at bottom. Main breadcrumb 工作空间 / 新任务. Quiet welcome centered above a large rounded message composer, title 今天，想一起完成什么？ and small subtitle 从一个目标开始，让协作有据可循。. Composer placeholder 描述你的目标…; bottom row small icons and 任务选项 / Agent / 技能, circular white arrow send button; thin lower line with 协作方式 黑板协作 and 完成条件 选择完成条件. Three low emphasis example shortcuts below. Avoid excessive border boxes or repeated logos.
SETTINGS: EXACT same outer rail, contextual sidebar width, header heights and main column alignment as home; settings icon active, sidebar has 返回工作空间, 模型连接, Agent 提示词, 运行配置. Breadcrumb 设置 / 模型连接. Main heading 模型连接 small descriptive subtitle. Clean flat grouped form with thin separators and aligned two-column fields, section headings 连接信息, 模型列表, 默认模型. Visible protocol segmented choices Responses / Chat / Claude; compact Base URL and API Key fields; models list with checkboxes and 获取模型 button. MOBILE inset shows the same home with rail/sidebar hidden, hamburger in compact topbar, composer fitted to width, all labels legible. Render as polished realistic frontend screenshot, not wireframe.
